# Easier parameter scans with hmcdj

**Authors:** Alexis Verney-Provatas, Ed Bennett, Gaurav Ray

We present hmcdj, a new tool developed to ease the process of generating large numbers of gauge ensembles for a given theory. Building on top of the Grid library, hmcdj allows quick specification of lattice gauge theories in C++ with minimal boilerplate, and precise specification of per-ensemble parameters to be controlled at run time from a YAML input file. Additionally, it supports many quality-of-life features for managing large numbers of running jobs, including automatic tuning of the molecular dynamics step size to control the Metropolis acceptance rate; output of ILDG-compliant data; and integration with HPC schedulers to dynamically adapt the target trajectory count of a job to match its time limits. hmcdj is openly available under the GPLv2 license, and welcomes new contributions.
