LVRE: A Local Visual Reasoning and Editing Agent for Optical Chemical Structure Recognition

Bowen Lin, Lei Fan

arXiv:2611.18717·cs.CV·Published 2026-11-08

Optical chemical structure recognition (OCSR) demands strict all-or-nothing graph fidelity, where a single misidentified bond order or formal charge makes the predicted graph differ from the reference structure. While vision-language models (VLMs) can reinspect ambiguous visual regions, unconstrained full-graph regeneration often introduces regressive errors into previously correct substructures. We present LVRE, a training-free visual agent that refines molecular graphs via targeted visual inspection and reversible transactional editing. Rather than regenerating the entire graph sequence, LVRE examines a high-resolution crop alongside the global diagram and local graph neighborhood, proposing modifications to named graph records that a deterministic controller checks. A controller executes each proposed modification as an isolated transaction, and a visual review module arbitrates which edits to commit or roll back. Across four foundation VLMs, LVRE improves graph accuracy by 8.0-8.5 percentage points over single-pass recognition and by 3.0-3.3 points over fixed local review. In a paired evaluation of 1,000 diagrams using Gemini 3.8 Flash, LVRE achieves 100 successful repairs while introducing only 15 regressive errors, in contrast to global reflection which yields 65 repairs against 30 introduced errors. On this paired set, LVRE introduces half as many errors on initially correct predictions as global reflection.
