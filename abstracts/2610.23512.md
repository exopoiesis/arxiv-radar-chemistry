# topas-editor and TOPilot: tools for AI-driven analysis of diffraction and total scattering data

**Authors:** John S. O. Evans, Oliver J. Wagstaff, Ivana R. Evans, Arnt Kern, Alan A. Coelho

This paper describes topas-editor and TOPilot, which provide a powerful interface to the TOPAS software suite and allow generative AI-driven automation of complex crystallographic tasks. topas-editor is a TOPAS-aware VS Code extension designed for the rapid creation and editing of TOPAS input files and for interacting with the software. It knows TOPAS syntax, has crystallographic-aware editing features and provides in-line user guidance via hover tips and automated links to reference manuals. TOPilot is a collection of Python routines and machine-accessible reference documents that allow AI-driven automated analysis in TOPAS. It uses a transferable topas-inp-writer skill that can be applied in all TOPAS application areas. We demonstrate the power and reliability of the approach using examples including: a complex Rietveld refinement with sample- and data-related complications; automatic analysis of multiple data sets; a pipeline from indexing through structure solution to refinement; automatic identification of the phases present in a sample; single crystal and powder diffraction analysis of incommensurate structures; and fitting PDF data. TOPilot can be used directly alongside topas-editor, via a stand-alone topilot-wizard, or via command line interfaces or desktop apps from major AI providers. TOPilot was developed and tested using Claude large language models, but can be configured to use other cloud or local models. topas-editor and TOPilot are freely available.
