ARES: a plane-wave density-functional-theory code in Rust

Zehan Liu, Qian Wang, Xiangyu Zheng, Jiaxiang Li, Chuntian Wu, Yongshuo Chen, Xuecheng Shao, Qiang Xu, Yu Xie, Yanming Ma

arXiv:2610.17854·cond-mat.mtrl-sci·Published 2026-10-13

ARES (Ab initio atomic mateRial modEling Software at JLU) is a plane-wave density-functional-theory (DFT) code written entirely in Rust as a layered 22-crate workspace. It supports norm-conserving pseudopotentials and the projector augmented-wave (PAW) method with the local-density approximation (LDA) and Perdew-Burke-Ernzerhof (PBE) functionals, Γ-only and explicit k-point sampling, smearing and mixing, forces, stress, relaxation, band structures, densities of states (DOS) and dispersion corrections; execution is serial or MPI-distributed over k-point pools, band groups and plane-wave rows. The code's distinguishing engineering choice is its validation apparatus. Every numerical component is checked against Quantum ESPRESSO driven from the same physical and numerical inputs, and the comparison is organized as numbered fixtures kept in the repository whose reference data is regenerated by a script instead of being captured once. On six materials spanning a semiconductor, three metals and two two-dimensional systems, band energies within one electronvolt of the Fermi level agree with the reference to a median below 0.4 meV. The pseudopotentials the code reads are validated against all-electron reference data as well: the median delta factor is 0.696 meV/atom over all 65 paired elements. Restrictions are stated with the capabilities: two functionals, no spin-polarized or spin-orbit path, a stress implementation with an explicit scope, and no accelerator execution.
